# Contributing to StockForge

Thank you for your interest in contributing to **StockForge** !

Contributions, suggestions, bug reports, and feature requests are welcome. Every contribution helps make StockForge better.

## Getting Started

1. Fork the StockForge repository.
2. Clone your fork:
   **bash**

   ```
   git clone https://github.com/ukihunter/StockForge.git
   ```

3. Navigate to the project directory:
   **bash**

   ```
   cd StockForge
   ```

4. Install the dependencies:
   **bash**

   ```
   npm install
   ```

5. Start the development environment:
   **bash**

   ```
   npm run tauri dev
   ```

## How to Contribute

1. Create a new branch:
   **bash**

   ```
   git checkout -b feature/your-feature-name
   ```

2. Make your changes.
3. Test your changes.
4. Commit your changes:
   **bash**

   ```
   git add .
   git commit -m "feat: add your feature"
   ```

5. Push your branch:
   **bash**

   ```
   git push origin feature/your-feature-name
   ```

6. Open a Pull Request against the main StockForge repository.

## Contribution Guidelines

- Keep code clean, readable, and maintainable.
- Follow the existing project structure and coding conventions.
- Write meaningful commit messages.
- Test your changes before submitting a Pull Request.
- Avoid introducing unnecessary dependencies.
- Provide clear descriptions of your changes.

## Reporting Bugs

When reporting a bug, please include:

- A clear description of the issue.
- Steps to reproduce the problem.
- Expected behavior.
- Actual behavior.
- Relevant error messages or screenshots.

## Feature Requests

Feature suggestions are welcome! Please explain the problem your feature would solve and how it could improve StockForge.

## Code of Conduct

Be respectful, constructive, and welcoming to everyone participating in the project.

Thank you for helping improve StockForge!
