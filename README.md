**StockForge** is a local-first desktop application designed to streamline and organize the creation, management, and preparation of digital assets for Adobe Stock.

Built with **Tauri 2, Rust, React, and TypeScript**, StockForge combines the performance of a native desktop application with a modern web-based interface. It provides a centralized workspace for managing the entire stock asset production workflow, from asset creation and metadata preparation to organization and submission.

## Core Features

- **Dashboard:** Monitor production progress, asset statistics, and workflow activity from a centralized workspace.
- **Asset Management:** Import, organize, preview, and manage stock images and other digital assets.
- **AI-Assisted Metadata:** Generate titles, descriptions, and keywords to help prepare assets for stock marketplace submissions.
- **Production Pipeline:** Track assets through different stages of the production process.
- **Adobe Stock Workflow:** Prepare and manage assets for Adobe Stock submission with browser-assisted workflows.
- **Local-First Storage:** Keep project data and assets on the user's machine, reducing dependence on cloud infrastructure.
- **Automation:** Streamline repetitive production and asset-management tasks.

## Technology Stack

- **Desktop Framework:** Tauri 2
- **Backend:** Rust
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS v4
- **UI Components:** shadcn/ui
- **Icons:** Lucide React
- **Database:** SQLite
- **Browser Automation:** Chromium-based automation

## Vision

The goal of StockForge is to create a reliable, efficient, and extensible desktop workspace that simplifies stock asset production.

By combining local processing, intelligent automation, and an organized production pipeline, StockForge aims to help creators manage their stock content workflow more efficiently.
